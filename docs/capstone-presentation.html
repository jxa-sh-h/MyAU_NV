Modern Student Portal

A responsive student-services concept for Angeles University Foundation

Interactive frontend demonstration · 2026

01 · Project motivation

A clearer path through student services

Problem

Academic records, schedules, enrollment, and account tasks need a consistent, easy-to-scan portal experience across devices.

Objective

Demonstrate familiar student workflows with clearer hierarchy, accessible controls, responsive navigation, and useful feedback.

This capstone is a frontend concept. It is not an official AUF service and does not connect to university systems.

02 · Users and scope

Designed around student tasks

Target users

  • AUF students reviewing academic progress
  • Students checking schedules and enrollment
  • Students managing campus-service tasks

Design priorities

  • One consistent portal shell and navigation
  • Readable information and status at a glance
  • Accessible forms, dialogs, and responsive tables

05 · Technical architecture

Lightweight, reusable frontend

React + React RouterFunctional components, shared layout, and client-side routes.
Vite + Bootstrap + MYAU CSSFast development/build tooling with reusable design tokens and responsive styles.
Mock data + localStorageFictional records and browser-local demo persistence, no backend.
Static deploymentVite production output can be hosted on a static platform with SPA route fallback.

06 · Interaction and data boundary

Useful feedback without real transactions

Simulated workflows

  • Add/drop a mock subject
  • Submit a clearance item for review
  • Preview a payment and update demo history
  • Save or remove faculty evaluation records

Browser-local features

  • Search, sort, and filter records
  • Edit fictional profile details
  • Renew a sample library loan
  • Switch theme and clear demo data

No credentials, real student records, official enrollment requests, faculty evaluations, or payment details are sent or processed.

07 · Validation and live demo

Build, verify, demonstrate

Verification completed

  • Production build with Vite
  • All ten module routes rendered
  • Enrollment, payments, clearance, and evaluation flows exercised
  • Desktop/mobile dashboard output checked

Suggested live demo

  1. Review dashboard and open a module
  2. Search a grade or schedule entry
  3. Preview an enrollment or payment action
  4. Switch to mobile navigation and dark mode

Deployment to a public host and GitHub publishing require the student's hosting account and repository connection.
